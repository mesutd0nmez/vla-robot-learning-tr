## Sent by the advisor later
- [Webots — Cyberbotics](https://cyberbotics.com/) (16 Nov 2026) — open-source robot simulator (since 1998; Windows/Linux/macOS). Physics: ODE fork; renderer: wren (OpenGL 3.3); controller languages C/C++/Python/Java/MATLAB/ROS; ROS 2 (with Vulcanexus). Ready-made models: UR10e, ABB IRB 4600, KUKA youBot, TIAGo, TurtleBot3, PR2, Nao, OP3… Extras: [webots.cloud](https://webots.cloud) (sharing/competitions), [robotbenchmark.net](https://robotbenchmark.net) (free online programming tasks), [GitHub](https://github.com/cyberbotics/webots). Its place in the plan: Lecture 21 — comparison with MuJoCo/LIBERO and the environment decision for the thesis.
